# 📊 Project 2: Data Classification Using AI
### DecodeLab Internship

## 📌 About This Project
A machine learning project that predicts the Order Status of e-commerce orders
such as Delivered, Shipped, Cancelled, Returned, and Pending.
Built using Decision Tree Classifier and Random Forest Classifier trained on a real dataset.

## 🎯 What It Does
- Loads and explores a real e-commerce dataset
- Cleans and encodes the data for the model
- Splits data into 80 percent training and 20 percent testing
- Trains a Decision Tree classification model
- Trains a Random Forest classification model
- Compares accuracy of both models
- Shows accuracy score and confusion matrix chart
- Predicts order status for new order inputs

## 🛠️ Skills Used
- Python and Pandas for data handling
- Scikit-learn for machine learning
- Matplotlib and Seaborn for charts
- Supervised learning and classification
- Model comparison and evaluation techniques

## 🤖 Models Used
- Decision Tree Classifier — simple and visual flowchart based model
- Random Forest Classifier — stronger model that combines multiple decision trees

## 📦 Dataset Info
- File name: Dataset_for_Data_Analytics.xlsx
- Features used: Product, Quantity, UnitPrice, PaymentMethod, TotalPrice, ItemsInCart
- Target column we predict: OrderStatus

## 🚀 How to Run
1. Open Google Colab at colab.research.google.com
2. Click File then Upload Notebook
3. Upload the file Project2_Data_Classification.ipynb
4. When the notebook asks you to upload a file, select Dataset_for_Data_Analytics.xlsx
5. Run each cell one by one using Shift + Enter

- Confusion matrix heatmap for Random Forest
